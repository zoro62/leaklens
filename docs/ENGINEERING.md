# Interview notes

- **One coordinate space:** browser orientation-aware decoding produces a normalised full-size canvas. The OCR/QR canvas uses a maximum edge of 2400px. Independent x/y ratios map every detected word and QR corner back to original pixels; export never uses the downscaled raster.
- **Span-to-word evidence:** OCR preserves word offsets in reading order. Regex matches overlap offsets to collect only participating word boxes. A match across words or lines does not cover a giant intervening region.
- **Risk and confidence differ:** a strong regex match for a URL is still context. An address is an uncertain inference. Credential-shaped content is never described as a confirmed active credential.
- **Relationships are inspectable:** deterministic rules require explicit entity types and a region gap under 280 original pixels (or the same QR). Members are linked. This is an explainable prototype heuristic; font-relative/block-aware proximity is a useful next improvement.
- **Workers have owners:** QR decoding runs in its own worker. An OCR orchestration worker owns Tesseract's nested worker, so termination also bounds startup failures. A revision counter prevents stale uploads, demo fetches, scans and rechecks from committing after replacement/clear.
- **Redaction changes the artifact:** a fresh canvas receives source pixels and opaque black rectangles. The encoder emits a new PNG without copying source metadata. QR redaction covers the entire polygon's bounding rectangle plus padding.
- **Privacy is architectural:** no image API, no model API, no image persistence, no live credential validation. Engine assets are self-hosted, language caching is disabled, and raw evidence is in memory only. Releasing references is not secure memory erasure.
- **Measured claims:** fixtures use the same real pipeline as uploads. Browser tests inspect exported pixel opacity, unchanged pixels and full dimensions; independent ZXing checks demonstrate that the fixture QR is readable before and undetectable after redaction. Synthetic tests are not a real-world accuracy benchmark.
- **Thorough means actual additional work:** an overview plus sequential overlapping original-resolution crops are analysed by the real workers. Offsets restore every box to the normalised source. Deduplication requires identical evidence and spatial overlap; identical values elsewhere remain separate. A failed tile makes the overall result partial. Manual edits survive rescanning; automatic findings restart so new detections receive the documented defaults.
- **Preview the artifact:** the comparison and reviewed download use the same PNG blob, rather than a CSS approximation. It is revoked when edits invalidate it. A regression compares the blob bytes with downloaded bytes and checks revocation. Original image content is deliberately visible in the comparison and labelled private.
- **Suggestions preserve user decisions:** presets only add selections, while restoring defaults is explicit and undoable. Batch actions synchronise whole QR codes and preserve manual rectangles/dismissals. Review prompts are user attestations, never an automated safety verdict.
- **Constrained AI:** Gemini only orders allowlisted advice based on typed category counts and rule IDs. Fixed wording prevents unsupported model claims; explicit consent, strict schemas, local-only access, timeout and a process-wide quota bound the optional remote boundary.

# Security considerations and reports

LeakLens is a hackathon prototype that assists human review. It cannot find every disclosure or guarantee complete anonymisation. Read the README and `docs/THREAT-MODEL.md` before relying on its output.

For ordinary bugs, provide a synthetic reproduction and steps to reproduce. Do not put real screenshots, QR payloads, credentials or personal information in public issues, pull requests or logs.

For a sensitive vulnerability, contact the repository owner through an available private channel. If GitHub private vulnerability reporting is enabled on the repository, use its Security tab. This document does not imply that private reporting has been enabled or promise a response time.
